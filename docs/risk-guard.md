# Risk Guard — โล่บัญชี Fixed-Point $50

> อัปเดต: 13 กันยายน 2026

## วัตถุประสงค์
บังคับวินัยบัญชีไมโครให้ขาดทุนต่อไม้ไม่เกินกรอบที่กำหนด แม้โบรกเกอร์จะมีเลเวอเรจสูง (เช่น FBS-Demo 1:2000)

## ค่าคงที่ (`config/settings.py`)

| ค่า | ความหมาย |
|-----|----------|
| `ACCOUNT_INITIAL_BALANCE = 50` | **โมเดลความเสี่ยงอ้างอิง** (ใช้คำนวณเพดาน $2.50) |
| `MAX_RISK_DOLLARS_PER_TRADE = 2.50` | ขาดทุนสูงสุดต่อไม้ = 5% ของ $50 |
| `FIXED_LOT_SIZE = 0.01` | lot เดียวที่อนุญาต |
| `MAX_CONCURRENT_POSITIONS = 1` | เปิดได้ทีละ 1 ไม้ทั้งบัญชี |

## กฎที่ตรวจใน `subsystems/risk_guard/guard_50.py`
1. Lot ต้องเป็น 0.01  
2. ระยะ SL แปลงเป็นเงินแล้ว ≤ $2.50  
3. ไม่มีโพซิชันเปิดอยู่แล้ว  
4. สเปรดไม่เกินเพดานของสัญลักษณ์  
5. ไม่อยู่ช่วง rollover / Red Folder halt  

## สำคัญ: คนละเรื่องกับยอดบน Dashboard

| แนวคิด | ที่มา | ใช้ทำอะไร |
|--------|------|-----------|
| ยอดตั้งต้นบน UI | MT5 `DEAL_TYPE_BALANCE` / ประวัติดีล | แสดง PnL% จริงของบัญชี (เช่น ฝาก $1000 → equity $760) |
| `$50` / `$2.50 MAX` | `config/settings.py` | กฎกลยุทธ์บอท ไม่ได้บังคับให้บัญชีมีแค่ $50 |

หน้า **Portfolio & risk** แสดง Initial จาก MT5  
ป้าย **Risk guard ARMED · $2.50 MAX** ยังคงเป็นกฎกลยุทธ์

## Output
- ผ่าน → ส่งต่อไป Execution (`exec.trade` เมื่อมีการเติม/ปิด)  
- ไม่ผ่าน → เหตุผล reject (dashboard แจ้งเตือนได้)
